# Decision framework

Evaluate:

**Revenue probability × long-term upside × founder fit × compounding assets**

and penalize:

**time waste × capital intensity × luck dependency × premature complexity.**

# Strategic tests

- Can it be sold before it is deeply automated?
- Is there a clear buyer and painful problem?
- Can technical capability create measurable leverage?
- Can initial service become software/systemized?
- Is distribution available or buildable?
- Does it create compounding data, workflow, reputation, or software assets?

This is a current operating framework, not a universal rule.
